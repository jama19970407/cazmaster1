# CazMaster1 — HTML Loyihalar To'plami

## QANDAY HTML LOYIHANI BU YERGA YUKLAYMAN? / HOW TO UPLOAD AN HTML PROJECT HERE?

---

### 🇺🇿 O'zbekcha Ko'rsatma

Yangi HTML loyihani repozitoriyga qo'shish uchun quyidagi qadamlarni bajaring:

1. **Yangi papka yarating** — Loyihangiz uchun mos nom bilan papka yarating (masalan: `MyGame`).

2. **Fayllarni papkaga joylashtiring** — Papkaga quyidagi fayllarni qo'shing:
   - `index.html` — Asosiy HTML fayli
   - `index.css` — Stil fayli (agar kerak bo'lsa)
   - `script.js` — JavaScript fayli (agar kerak bo'lsa)
   - `images/` — Rasm va media fayllar uchun papka (agar kerak bo'lsa)

3. **GitHub'ga yuklang:**
   - GitHub saytida repozitoriyni oching
   - `Add file` → `Upload files` tugmasini bosing
   - Fayllaringizni tanlang yoki sudrab olib tashlang
   - `Commit changes` tugmasini bosing

**Papka tuzilishi namunasi:**
```
MyGame/
├── index.html
├── index.css
├── script.js
└── images/
    └── logo.png
```

---

### 🇬🇧 English Instructions

To add a new HTML project to this repository, follow these steps:

1. **Create a new folder** — Create a folder with a suitable name for your project (e.g. `MyGame`).

2. **Place your files in the folder** — Add the following files:
   - `index.html` — Main HTML file
   - `index.css` — Stylesheet (if needed)
   - `script.js` — JavaScript file (if needed)
   - `images/` — Folder for images and media assets (if needed)

3. **Upload to GitHub:**
   - Open the repository on GitHub
   - Click `Add file` → `Upload files`
   - Select or drag-and-drop your files
   - Click `Commit changes`

**Example folder structure:**
```
MyGame/
├── index.html
├── index.css
├── script.js
└── images/
    └── logo.png
```
